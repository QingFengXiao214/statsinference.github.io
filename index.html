Metric definitions

For each test dataset, θ is the true parameter, θ^ is its estimate, [L,U] is the reported 95% interval, and t is the time required to compute both. The estimation error is e=θ^−θ. E denotes expectation over the test-data distribution; the leaderboard reports empirical estimates of the quantities below.

Bias
Bias=E[e]

The signed average estimation error. Positive values indicate overestimation; negative values indicate underestimation. Values closer to zero indicate less average bias.

Variance
Vsampling=EC[Var(θ^|C)]

Sampling variance measures variation between independent datasets for a fixed test setting C (the generating distribution and any query point), then averages over test settings. It is used for Average Treatment Effect, Conditional Average Treatment Effect and Mediation.

Verror=E[(e−E[e])2]

Error variance measures the spread of estimation errors across test datasets. It is used for Instrumental Variables, Proximal Causal Inference and Difference-in-Differences.

Root mean squared error (RMSE)
RMSE=E[e2]

The overall magnitude of estimation error, including both bias and variability. Lower values indicate more accurate point estimates.

Interval length
Length=E[U−L]

The average width of the reported interval. Narrower intervals are more informative only when they provide adequate coverage.

Coverage
Coverage=100×Pr(L≤θ≤U)

The percentage of intervals that contain the true parameter. The nominal level is 95%; values above 95% are not automatically better.

Inference time
Time=E[t]

The average wall-clock time, in seconds per dataset, to produce both the point estimate and its interval. For RF + bootstrap, this includes fitting the original dataset and all bootstrap refits.

For standardized scores, the error is (θ^−θ)/s and interval length is (U−L)/s, where s is the sample standard deviation of the observed outcome. Coverage and time are unchanged.
