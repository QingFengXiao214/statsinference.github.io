# Method submissions

[View submitted methods](received/README.md)

Submit a Hugging Face model link using **Submit your method** on the [website](https://statsinference.github.io/), then confirm the prefilled submission on GitHub. A GitHub account is required. Submissions are public.

Each confirmed submission is automatically saved as a JSON record in `received/` and added to the list above. The research repository periodically imports the same records into its `method-submissions/received/` folder. No model is downloaded or executed by the intake workflow.
